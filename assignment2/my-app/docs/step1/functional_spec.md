# Step 1 — 기능 명세

## 구현 범위

기본 CRUD + 완료 토글 + 인라인 수정: 할 일을 추가·수정·완료·삭제할 수 있는 핵심 기능을 구현한다.
상태는 컴포넌트 내 메모리(React state)에만 저장하며, localStorage는 이 단계에서 사용하지 않는다.

## 기능 목록

| # | 기능 | 설명 |
|---|------|------|
| F1-01 | 할 일 추가 | 입력창에 텍스트 입력 후 Enter 키 또는 추가 버튼으로 항목 추가 |
| F1-02 | 빈 입력 방지 | 공백만 있는 입력은 추가되지 않아야 한다 |
| F1-03 | 입력창 초기화 | 추가 후 입력창이 자동으로 비워진다 |
| F1-04 | 할 일 목록 표시 | 추가된 항목들이 목록으로 렌더링된다 |
| F1-05 | 할 일 삭제 | 각 항목에 삭제 버튼이 있고, 클릭 시 해당 항목이 제거된다 |
| F1-06 | 완료 토글 | 각 항목에 완료 체크박스(또는 버튼)가 있고, 클릭 시 완료/미완료 상태가 전환된다 |
| F1-07 | 완료 시각적 표시 | 완료 상태인 항목은 텍스트에 취소선이 표시되는 등 미완료 항목과 시각적으로 구분된다 |
| F1-08 | 인라인 수정 | 수정 버튼 클릭 시 텍스트가 input 요소로 전환되고, Enter 키 또는 저장 버튼으로 확정된다 |
| F1-09 | 수정 취소 | 수정 모드에서 Escape 키를 누르면 변경 사항 없이 수정 모드가 종료된다 |
| F1-10 | 완료된 항목 수정 불가 | 완료 처리된 항목의 수정 버튼은 비활성화(disabled)된다 |

## 완성 기준

- 텍스트 입력 후 Enter / 버튼 클릭으로 목록에 항목이 추가된다
- 삭제 버튼 클릭 시 해당 항목만 제거된다
- 빈 문자열은 목록에 추가되지 않고, 사용자에게 안내 메시지가 표시된다
- 완료 버튼(또는 체크박스) 클릭 시 완료/미완료 상태가 전환되며, 완료 항목은 취소선으로 시각적으로 구분된다
- 수정 버튼 클릭 시 `prompt()` 없이 항목 텍스트가 인라인 input으로 전환된다
- 수정 확정(Enter/저장) 시 변경된 텍스트가 반영되고, 취소(Escape) 시 원래 텍스트가 유지된다
- 완료 처리된 항목은 수정 버튼이 비활성화된다

## 컴포넌트 책임 분배

| 컴포넌트 | 담당 기능 |
|---------|---------|
| `App.jsx` | `todoList` 상태 소유, 모든 핸들러 정의, 하위 컴포넌트에 props 전달 |
| `TodoInput.jsx` | F1-01, F1-02, F1-03 — 입력창, 추가 버튼, 에러 메시지 |
| `TodoList.jsx` | F1-04 — 목록 렌더링, `TodoItem` 반복 출력 |
| `TodoItem.jsx` | F1-05~F1-10 — 삭제, 완료 토글, 인라인 수정 |
