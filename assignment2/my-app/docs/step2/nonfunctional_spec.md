# Step 2 — 비기능 명세

## 코드 품질

Step 2는 별도 파일을 추가하지 않는 검증 단계다.
Step 1의 NF 요구사항을 모두 상속하며, 아래 항목이 추가로 적용된다.

| # | 요구사항 | 기준 |
|---|---------|------|
| NF2-01 | 상태 불변성 | `toggleTodoComplete` 핸들러는 기존 배열을 직접 변경하지 않고 `map`으로 새 배열을 반환해야 한다 |
| NF2-02 | 완료 항목 수정 제한 | `TodoItem`에서 `todo.completed === true`인 경우 수정 버튼을 `disabled` 처리한다 |
| NF2-03 | 체크박스 접근성 | 체크박스에 `aria-label` 또는 연결된 `<label>` 을 제공해 스크린 리더가 상태를 읽을 수 있게 한다 |

|---|---------|------|
