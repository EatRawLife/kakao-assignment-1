# Step 2 — 기능 명세

## 구현 범위

완료 토글: 할 일의 완료/미완료 상태를 전환할 수 있도록 한다.
Step 1 기능(추가, 삭제)은 그대로 유지한다.

## 기능 목록

| # | 기능 | 설명 |
|---|------|------|
| F2-01 | 완료 토글 | 체크박스 클릭 시 해당 항목의 완료 상태가 전환된다 |
| F2-02 | 완료 항목 시각 처리 | 완료된 항목은 텍스트에 취소선이 표시되고 색이 흐려진다 |
| F2-03 | 상태 유지 | 다른 항목을 추가·삭제해도 각 항목의 완료 상태가 유지된다 |

## 완성 기준

- 체크박스 클릭 시 완료/미완료 상태가 즉시 전환된다
- 완료 항목과 미완료 항목이 시각적으로 구분된다
- 새로운 항목 추가 시 기존 항목의 완료 상태가 변하지 않는다
