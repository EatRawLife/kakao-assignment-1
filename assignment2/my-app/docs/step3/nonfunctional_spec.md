# Step 3 — 비기능 명세

## 코드 품질

| # | 요구사항 | 기준 |
|---|---------|------|
| NF3-01 | 컴포넌트 분리 | `TodoFilter.jsx`를 독립 파일로 작성한다. `App.jsx`에 인라인으로 작성하지 않는다 |
| NF3-02 | 상수 파일 분리 | 필터 타입은 `constants/filters.js`에서 `FILTER_ALL`, `FILTER_ACTIVE`, `FILTER_COMPLETED`로 정의한다. 컴포넌트 내부에 문자열 리터럴을 직접 쓰지 않는다 |
| NF3-03 | 필터 기본값 | `filterType` 초기값은 반드시 `FILTER_ALL`로 설정한다 |
| NF3-04 | 파생 상태 | `filteredTodoList`는 `todoList`에서 `filter()`로 파생한다. 별도 state로 관리하지 않는다 |
| NF3-05 | 주석 | `TodoFilter.jsx`와 `constants/filters.js`에 역할·props·상수 설명 주석을 작성한다 |

## 디자인 / UX

| # | 요구사항 | 기준 |
|---|---------|------|
| NF3-06 | 활성 탭 강조 | 선택된 탭은 `#672be0` 색상 계열로 강조하고, 비선택 탭과 시각적으로 명확히 구분한다 |
| NF3-07 | 탭별 빈 상태 메시지 | 필터 결과가 없을 때 탭 상황에 맞는 안내 문구를 표시한다 |

| 탭 | 빈 상태 메시지 |
|----|--------------|
| 전체 | "할 일이 없습니다. 새로운 할 일을 추가해보세요!" |
| 진행 중 | "진행 중인 할 일이 없습니다." |
| 완료 | "완료된 할 일이 없습니다." |

| NF3-08 | 목록 요약 | 전체 항목 수와 완료 항목 수를 `전체 N개 · 완료 N개` 형식으로 표시한다 |
