# Step 3 — 에러 케이스

## EC3-01: 필터 결과가 빈 목록일 때

| 항목 | 내용 |
|------|------|
| **상황** | 선택한 탭 조건에 해당하는 항목이 하나도 없는 경우 |
| **예시** | "완료" 탭인데 완료된 항목이 없음 / "진행 중" 탭인데 모든 항목이 완료됨 |
| **처리** | 빈 목록 대신 탭에 맞는 안내 메시지를 표시한다 (`TodoList` 내부에서 처리) |
| **에러 메시지** | NF3-07 탭별 빈 상태 메시지 참조 |
| **구현 포인트** | `filteredTodoList.length === 0`일 때 조건부 렌더링으로 메시지 노출 |

---

## EC3-02: 진행 중 탭에서 마지막 항목을 완료 처리한 경우

| 항목 | 내용 |
|------|------|
| **상황** | "진행 중" 탭을 보는 중에 남은 유일한 항목의 체크박스를 클릭해 완료 처리 |
| **처리** | `filteredTodoList`가 즉시 빈 배열이 되고 "진행 중인 할 일이 없습니다." 메시지가 표시된다 |
| **구현 포인트** | 필터는 `todoList`에서 매 렌더링마다 파생되므로 자동 처리된다. 별도 처리 불필요 |

---

## EC3-03: 완료 탭에서 항목을 삭제한 경우

| 항목 | 내용 |
|------|------|
| **상황** | "완료" 탭에서 완료된 항목의 삭제 버튼 클릭 |
| **처리** | 해당 항목만 `todoList`에서 제거된다. 다른 탭의 항목은 영향받지 않는다 |
| **구현 포인트** | `handleDeleteTodo`는 id로만 삭제하므로 필터 상태에 무관하게 올바르게 동작한다 |

---

## 에러 상태 흐름 요약

```
탭 클릭
      ↓
handleChangeFilter(type) → filterType 상태 변경
      ↓
filteredTodoList = todoList.filter(탭 조건)
      ↓
  결과 있음                   결과 없음
    ↓                           ↓
  항목 목록 렌더링         빈 상태 메시지 렌더링
```
