# Step 3 — 기능 명세

## 구현 범위

필터링: 전체 / 진행 중 / 완료 탭으로 목록을 필터링할 수 있도록 한다.
Step 1~2 기능은 그대로 유지한다.

## 기능 목록

| # | 기능 | 설명 |
|---|------|------|
| F3-01 | 전체 탭 | 모든 할 일 항목을 표시한다 |
| F3-02 | 진행 중 탭 | 완료되지 않은 항목만 표시한다 |
| F3-03 | 완료 탭 | 완료된 항목만 표시한다 |
| F3-04 | 활성 탭 표시 | 현재 선택된 탭이 시각적으로 구분된다 |
| F3-05 | 필터 유지 | 항목 추가·삭제·토글 후에도 현재 필터가 유지된다 |

## 완성 기준

- 탭 클릭 시 해당 조건에 맞는 항목만 목록에 표시된다
- 선택된 탭이 강조 표시된다
- 필터 상태 중 항목을 조작해도 필터가 초기화되지 않는다
